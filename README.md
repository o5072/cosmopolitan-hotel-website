# Cosmopolitan Hotel Website

A responsive luxury hotel website with separate pages for home, rooms and suites, booking, payment, and about/contact.

## Pages

- `index.html` - cinematic home page
- `rooms.html` - room categories and reservations
- `booking.html` - step-by-step reservation form
- `payment.html` - payment checkout screen
- `about.html` - hotel story, map placeholder, and contact form

## Local Preview

```powershell
node server.js
```

Then open `http://127.0.0.1:8080/`.
